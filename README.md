# QCA Hardware onboarding project FA2026

**Authors : Ivan Mokeyev**

**Date    : August 29th, 2026**

This is the repository for onboarding for the hardware team. Everyone will submit their individual work, but you can collaborate individually. In this repo, we have two on-boarding projects at two difficulty levels:
- **Pattern Detector**: a simple design for people who are taking ECE 2300 or are new to Verilog and Digital Logic
- **Synchronous FIFO**: a slightly more difficult design for people who are taking/have taken ECE 4750 (comp arch), or if you have first done the detector design.

Each design is written and verified in `sim/`, then taken through an FPGA implementation flow in `fpga/`.

## Getting Started

Source the QCA setup script to load the tools (VCS, cocotb, Verilator, Vivado, pyhflow):

```
% source /classes/qca/setup-qca.sh
```

### Simulation

Implement your design in `sim/<design>/src` and write tests in `sim/<design>/test`, then run them from the test directory:

```
% cd sim/fifo/test
% make
```

### FPGA Flow

The flow is generated by pyhflow from a design yml in `fpga/designs`. Each step in `fpga/steps` is a template that pyhflow fills in with the variables from the yml. The simulation steps run only the subset of tests listed under `tests:` in the yml, reusing the testbench in `sim/`.

```
% mkdir -p fpga/build-fifo
% cd fpga/build-fifo
% pyhflow ../designs/fifo.yml
% ./run-flow            # run every step, or run one with ./02-synth/run
```

Each step writes a `run.log`; synthesis also writes `outputs/` and `reports/`.

For detailed instructions, follow [Guide.md](Guide.md).
